`-(으)려고 하다` 接喺動詞後面，表示某個人有意圖或者計劃做某件事。中文可以理解成「打算……」、「準備……」或者「諗住……」。

```text
다른 회사로 옮기려고 해요.
我打算轉去另一間公司。
```

## 文法接法

將動詞嘅 `-다` 刪走，再根據語幹有冇 받침，接上 `-려고 하다` 或者 `-으려고 하다`。

| 動詞語幹 | 接法 | 例子 |
|---|---|---|
| 冇 받침 | `-려고 하다` | 가다 → 가려고 하다 |
| 有 `ㄹ` 받침 | `-려고 하다` | 만들다 → 만들려고 하다 |
| 有其他 받침 | `-으려고 하다` | 먹다 → 먹으려고 하다 |

### 冇 받침

```text
그만두다 → 그만두려고 하다
옮기다 → 옮기려고 하다
```

### 有 받침

```text
먹다 → 먹으려고 하다
읽다 → 읽으려고 하다
```

`ㄹ` 받침比較特別，直接接 `-려고 하다`，唔需要加 `으`。

```text
만들다 → 만들려고 하다
살다 → 살려고 하다
```

## 例句

### 1. 表達自己嘅打算

```text
저는 지금 다니는 회사를 그만두려고 해요.
我打算辭去而家任職嘅公司。
```

`그만두다` 冇 받침，所以變成 `그만두려고 해요`。

### 2. 表達之後嘅計劃

```text
다음 달에 다른 회사로 옮기려고 해요.
我打算下個月轉去另一間公司。
```

`옮기다` 冇 받침，所以變成 `옮기려고 해요`。

### 3. 有 받침 嘅動詞

```text
오늘 저녁에 친구하고 같이 밥을 먹으려고 해요.
我今晚打算同朋友一齊食飯。
```

`먹다` 有 `ㄱ` 받침，所以要接 `-으려고 하다`：

```text
먹다 → 먹으려고 하다
```

### 4. 詢問對方嘅打算

```text
주말에 뭐 하려고 해요?
你週末打算做咩？
```

`-(으)려고 하다` 亦可以用喺問句，詢問對方之後打算做咩。

### 5. 表達之前嘅打算

```text
어제 일찍 자려고 했는데 일이 늦게 끝났어요.
琴日原本打算早啲瞓，但係工作好夜先完。
```

將 `하다` 變成過去式，就會成為 `-(으)려고 했어요`，表示喺過去某個時間有過呢個打算。

```text
자려고 해요
打算瞓覺

자려고 했어요
原本打算瞓覺
```

`-(으)려고 했어요` 本身只表示當時有呢個打算。最後有冇實行，要睇句子後面提供嘅情境。

## 今日單字

### 그만두다

**詞性：** 動詞  
**意思：** 停止、辭去、放棄繼續做某件事

常見搭配：

```text
회사를 그만두다
辭去公司嘅工作

일을 그만두다
辭職／停止工作

공부를 그만두다
停止學習
```

今篇例句：

```text
저는 지금 다니는 회사를 그만두려고 해요.
我打算辭去而家任職嘅公司。
```

### 옮기다

**詞性：** 動詞  
**意思：** 將人或者物件移去另一個地方；轉換位置、住所或者工作地點

常見搭配：

```text
자리를 옮기다
轉換座位

짐을 옮기다
搬運行李

직장을 옮기다
轉工

다른 회사로 옮기다
轉去另一間公司
```

今篇例句：

```text
다음 달에 다른 회사로 옮기려고 해요.
我打算下個月轉去另一間公司。
```

## 另一個用法：即將發生

除咗表示某個人嘅打算，`-(으)려고 하다` 亦可以表示某件事即將發生或者開始。

```text
해가 지려고 해요.
太陽就嚟落山。
```

呢個用法唔係話太陽有意圖做某件事，而係表示某種變化即將發生。

## `-(으)려고 하다` 同 `-(으)려고`

兩者形式相似，但句子入面嘅作用唔同。

### `-(으)려고 하다`

表示打算做某件事：

```text
한국어를 공부하려고 해요.
我打算學韓文。
```

### `-(으)려고`

連接前後兩個動作，表示做後面動作嘅目的：

```text
한국어를 공부하려고 한국에 갔어요.
為咗學韓文而去咗韓國。
```

第一句嘅重點係「有學韓文嘅打算」，第二句嘅重點就係「去韓國嘅目的係學韓文」。

## 總結

```text
冇 받침：動詞語幹 + -려고 하다
有 ㄹ 받침：動詞語幹 + -려고 하다
有其他 받침：動詞語幹 + -으려고 하다
```

`-(으)려고 하다` 主要用嚟：

1. 表達自己或者其他人嘅打算。
2. 詢問對方嘅計劃。
3. 透過 `-(으)려고 했어요` 表達之前有過嘅打算。
4. 表示某件事或者變化即將發生。
