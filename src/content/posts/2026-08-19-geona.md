`-거나` 接喺動詞或者形容詞後面，用嚟連接兩個或以上嘅選項。中文可以理解成「或者……」或者「……定係……」。

```text
주말에는 설거지를 하거나 방을 청소해요.
週末我會洗碗或者執房。
```

## 文法接法

將動詞或者形容詞嘅 `-다` 刪走，再接上 `-거나`。無論語幹有冇 받침，接法都一樣。

### 冇 받침

語幹冇 받침 時，直接接 `-거나`。

| 動詞 | 語幹 | 變化 |
|---|---|---|
| 가다 | 가- | 가거나 |
| 보다 | 보- | 보거나 |

### 有 받침

語幹有 받침 時，一樣直接接 `-거나`。

| 動詞 | 語幹 | 變化 |
|---|---|---|
| 먹다 | 먹- | 먹거나 |
| 읽다 | 읽- | 읽거나 |

形容詞都用同一接法，例如 `바쁘다 → 바쁘거나`、`좋다 → 좋거나`。

## `-거나` 同 `-(이)나`

兩個文法都可以解作「或者」，核心分別係接喺邊一類詞後面，同埋連接緊咩選項。

| 文法 | 接喺邊類詞後面 | 連接嘅內容 |
|---|---|---|
| `-거나` | 動詞、形容詞語幹 | 動作、狀態或者完整選項 |
| `-(이)나` | 名詞 | 人、事物、時間或者地方等名詞選項 |

### `-거나`：連接動作或者狀態

```text
커피를 마시거나 차를 마셔요.
我飲咖啡或者飲茶。
```

呢句用 `-거나` 連接 `커피를 마시다` 同 `차를 마시다` 兩個完整動作。無論語幹有冇 받침，都直接接 `-거나`。

名詞唔可以直接接 `-거나`。如果名詞喺句中作述語，就要透過 `이다` 接成 `이거나`：

```text
참가자는 학생이거나 선생님이에요.
參加者係學生或者老師。
```

呢句嘅 `이거나` 係 `이다 + -거나`，唔係助詞 `-(이)나`。

### `-(이)나`：連接名詞

```text
커피나 차를 마셔요.
我飲咖啡或者茶。
```

呢句用 `-(이)나` 連接 `커피` 同 `차` 兩個名詞，後面嘅 `마셔요` 由兩個選項共用。

`-(이)나` 要根據名詞有冇 받침 選擇形式：

```text
冇 받침：커피 → 커피나
有 받침：책 → 책이나
```

最簡單嘅判斷方法係：

```text
動詞／形容詞 + 或者：-거나
名詞 + 或者：-(이)나
```

`-(이)나` 仲可以表示「姑且揀一樣」或者強調數量比預期多等其他意思，所以唔係所有 `-(이)나` 都可以換成 `-거나`。今篇只比較兩者表示選擇時嘅用法。

## 例句

### 1. 連接兩個動作

```text
주말에는 설거지를 하거나 방을 청소해요.
週末我會洗碗或者執房。
```

`설거지를 하다` 刪走 `-다`，再接上 `-거나`，就會變成 `설거지를 하거나`。

### 2. 配合條件句使用

```text
시간이 있으면 책을 읽거나 영화를 봐요.
有時間嘅話，我會睇書或者睇戲。
```

`읽다` 同 `보다` 係兩個可以選擇嘅動作。通常最後一個選項唔需要再接 `-거나`。

### 3. 連接狀態同動作

```text
날씨가 춥거나 비가 오면 집에 있을 거예요.
如果天氣凍或者落雨，我會留喺屋企。
```

`-거나` 唔單止可以接動詞，亦可以接形容詞。呢句用 `춥다 → 춥거나` 連接「天氣凍」同「落雨」兩個情況。

### 4. 重複列出幾個選項

```text
저녁에는 음악을 듣거나 책을 읽거나 해요.
夜晚我會聽音樂、睇書之類。
```

重複使用 `-거나`，再以 `하다` 結尾，可以列出幾個可能會做嘅動作，語氣上亦可以表示仲有其他類似選項。

### 5. 表示結果唔受選項影響

```text
날씨가 춥거나 덥거나 상관없이 매일 산책해요.
無論天氣凍定熱，我每日都會散步。
```

`A-거나 B-거나 상관없이` 表示無論係 A 定 B，後面嘅結果都唔會改變。呢個用法唔係叫人揀其中一個選項。

## 今日生字

### 설거지

**詞性：** 名詞  
**意思：** 洗碗；清洗食完飯後用過嘅碗碟同廚具

常見搭配：

```text
설거지를 하다
洗碗

설거지를 끝내다
洗完碗

설거지를 돕다
幫手洗碗
```

`설거지` 係名詞，日常最常見嘅講法係 `설거지를 하다`。

今篇例句：

```text
주말에는 설거지를 하거나 방을 청소해요.
週末我會洗碗或者執房。
```

## 總結

```text
冇 받침：動詞／形容詞語幹 + -거나
有 받침：動詞／形容詞語幹 + -거나
名詞 + 이다：名詞 + 이거나
```

`-거나` 主要用嚟：

1. 連接兩個或以上嘅動作、狀態或者情況。
2. 表示其中一個選項可以發生或者被選擇。
3. 用 `A-거나 B-거나 하다` 列出幾個例子。
4. 用 `A-거나 B-거나 상관없이` 表示結果唔受選項影響。
