`-(으)ㄴ/는지 알다/모르다` 用嚟表達「知道／唔知道係咪……」或者「知道／唔知道邊個、邊度、幾時、點樣……」。

```text
인천행 열차가 어느 승강장에서 출발하는지 아세요?
你知唔知去仁川嘅列車喺邊個月台開出？
```

前面嘅內容本身係一個問題，但放入句入面之後唔會直接用問句結尾，而係接 `-(으)ㄴ/는지`，再接 `알다`、`모르다` 等動詞。

## 文法接法

接法要先分詞類：

- 動詞現在式接 `-는지`。
- 形容詞冇 받침 時接 `-ㄴ지`，有 받침 時接 `-은지`。
- 名詞直接接 `-인지`，唔受 받침 影響。

### 冇 받침

| 詞類 | 原形 | 變化 |
|---|---|---|
| 動詞 | 가다 | 가는지 알다／모르다 |
| 動詞 | 찾아보다 | 찾아보는지 알다／모르다 |
| 形容詞 | 비싸다 | 비싼지 알다／모르다 |
| 形容詞 | 크다 | 큰지 알다／모르다 |
| 名詞 | 무료 | 무료인지 알다／모르다 |

動詞無論有冇 받침，現在式都接 `-는지`。形容詞冇 받침 時接 `-ㄴ지`；名詞就直接接 `-인지`。

### 有 받침

| 詞類 | 原形 | 變化 |
|---|---|---|
| 動詞 | 먹다 | 먹는지 알다／모르다 |
| 動詞 | 찾다 | 찾는지 알다／모르다 |
| 形容詞 | 작다 | 작은지 알다／모르다 |
| 形容詞 | 좋다 | 좋은지 알다／모르다 |
| 名詞 | 학생 | 학생인지 알다／모르다 |

動詞有 받침 時仍然接 `-는지`；形容詞就接 `-은지`。名詞同樣直接接 `-인지`。

`아니다` 變成 `아닌지`：

```text
오늘이 휴일이 아닌지 확인해 보세요.
請確認今日係咪唔係假期。
```

### 不規則變化

| 類型 | 原形 | 變化 |
|---|---|---|
| `ㄹ` 받침 形容詞 | 멀다 | 먼지 |
| `ㅂ` 不規則 | 덥다 | 더운지 |
| `ㅅ` 不規則 | 낫다 | 나은지 |
| `ㅎ` 不規則 | 어떻다 | 어떤지 |
| `있다／없다` | 있다／없다 | 있는지／없는지 |

`있다` 同 `없다` 雖然用嚟描述狀態，但接法同動詞一樣，用 `있는지`、`없는지`。

## 過去同將來

過去發生嘅事用 `-았/었는지`；將來嘅事或者未確定嘅可能性用 `-(으)ㄹ지`。

| 時間 | 原形 | 變化 |
|---|---|---|
| 過去 | 가다 | 갔는지 알다／모르다 |
| 過去 | 찾아보다 | 찾아봤는지 알다／모르다 |
| 過去 | 비싸다 | 비쌌는지 알다／모르다 |
| 過去 | 무료이다 | 무료였는지 알다／모르다 |
| 將來／未確定 | 가다 | 갈지 알다／모르다 |
| 將來／未確定 | 먹다 | 먹을지 알다／모르다 |
| 將來／未確定 | 비싸다 | 비쌀지 알다／모르다 |
| 將來／未確定 | 무료이다 | 무료일지 알다／모르다 |

```text
열차가 어느 승강장에서 출발하는지 몰라요.
我唔知道架列車喺邊個月台開出。

열차가 제시간에 출발할지 몰라요.
我唔知道架列車會唔會準時開出。
```

第一句問緊現有資料；第二句講尚未發生、未能確定嘅事。

## 有疑問詞同冇疑問詞

有疑問詞時，重點係「邊個答案」；冇疑問詞時，重點通常係「係咪」。

| 類型 | 例子 | 意思 |
|---|---|---|
| 冇疑問詞 | 입장료가 무료인지 | 入場費係咪免費 |
| `얼마` | 입장료가 얼마인지 | 入場費幾多錢 |
| `어디` | 열차를 어디에서 타는지 | 喺邊度搭車 |
| `언제` | 열차가 언제 출발하는지 | 架車幾時開出 |
| `왜` | 왜 늦었는지 | 點解遲到 |
| `어떻게` | 역에 어떻게 가는지 | 點樣去車站 |

## `알아요`、`아세요`、`몰라요`、`모르겠어요`

- `알아요`：知道。
- `아세요?`：`알다` 嘅尊敬形式，用嚟有禮貌噉問對方知唔知道。
- `몰라요`：唔知道，語氣直接。
- `모르겠어요`：唔肯定／唔清楚，語氣比 `몰라요` 婉轉。

`-(으)ㄴ/는지` 要同前面嘅詞連寫，但同後面嘅動詞要分開：

```text
출발하는지 알아요. ✅
출발하는 지 알아요. ❌
```

## 例句

### 1. 入場費係咪免費

```text
입장료가 무료인지 아세요?
你知唔知入場費係咪免費？
```

`무료` 係名詞，所以接 `-인지`。

### 2. 列車喺邊個月台開出

```text
인천행 열차가 어느 승강장에서 출발하는지 몰라요.
我唔知道去仁川嘅列車喺邊個月台開出。
```

`출발하다` 係動詞，現在式接 `-는지`。

### 3. 月台遠唔遠

```text
입구에서 승강장까지 거리가 먼지 아세요?
你知唔知由入口行去月台遠唔遠？
```

`멀다` 有 `ㄹ` 받침，接 `-ㄴ지` 時會變成 `먼지`。

### 4. 有冇查過入場費

```text
친구가 입장료 정보를 찾아봤는지 모르겠어요.
我唔肯定朋友有冇查過入場費資料。
```

`찾아보다` 變成過去式 `찾아봤다`，再接 `-는지`，結果係 `찾아봤는지`。

### 5. 查吓喺邊度搭車

```text
인천행 열차를 어디에서 타는지 찾아봤어요.
我查過去仁川嘅列車要喺邊度搭。
```

間接疑問句除咗可以接 `알다`、`모르다`，亦可以接 `찾아보다`、`확인하다`、`묻다` 等動詞。

## 今日生字

### 입장료

**詞性：** 名詞  
**意思：** 入場費

常見搭配：

```text
입장료를 내다
畀入場費

입장료가 비싸다
入場費貴

입장료가 무료이다
免收入場費
```

今篇例句：

```text
입장료가 무료인지 아세요?
你知唔知入場費係咪免費？
```

### 무료

**詞性：** 名詞  
**意思：** 免費、免收費用

常見搭配：

```text
무료로 이용하다
免費使用

무료 서비스
免費服務

무료입장
免費入場
```

今篇例句：

```text
입장료가 무료인지 아세요?
你知唔知入場費係咪免費？
```

### 찾아보다

**詞性：** 動詞  
**意思：** 查找、查吓資料

常見搭配：

```text
인터넷에서 찾아보다
上網查

정보를 찾아보다
查資料

시간표를 찾아보다
查時間表
```

今篇例句：

```text
친구가 입장료 정보를 찾아봤는지 모르겠어요.
我唔肯定朋友有冇查過入場費資料。
```

### 인천행 열차

**詞性：** 詞組（名詞＋名詞）  
**意思：** 前往仁川嘅列車

`행` 放喺地名後面，表示交通工具前往嗰個地方。例如 `서울행` 係「前往首爾」，`부산행` 係「前往釜山」。

常見搭配：

```text
인천행 열차를 타다
搭去仁川嘅列車

인천행 열차가 출발하다
去仁川嘅列車開出

인천행 열차표
去仁川嘅列車車票
```

今篇例句：

```text
인천행 열차가 어느 승강장에서 출발하는지 몰라요.
我唔知道去仁川嘅列車喺邊個月台開出。
```

### 승강장

**詞性：** 名詞  
**意思：** 月台

常見搭配：

```text
승강장에서 기다리다
喺月台等

승강장으로 가다
去月台

승강장 번호
月台號碼
```

今篇例句：

```text
인천행 열차가 어느 승강장에서 출발하는지 몰라요.
我唔知道去仁川嘅列車喺邊個月台開出。
```

## 總結

- 動詞現在式接 `-는지`。
- 形容詞冇 받침 時接 `-ㄴ지`，有 받침 時接 `-은지`。
- 名詞接 `-인지`。
- 過去用 `-았/었는지`，將來或者未確定嘅事用 `-(으)ㄹ지`。
- 有疑問詞時表達「邊個、邊度、幾時、點樣」等資料；冇疑問詞時通常表達「係咪」。
- `-(으)ㄴ/는지` 同前面嘅詞連寫，同後面嘅動詞分開寫。
- 除咗 `알다`、`모르다`，間接疑問句亦可以接 `찾아보다`、`확인하다`、`묻다` 等動詞。
