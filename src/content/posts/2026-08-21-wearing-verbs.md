廣東話講「戴」或者「着」嘅時候，韓文唔會一律用同一個動詞。戴喺頭、套喺手指、着喺身同扣喺手腕，都有唔同嘅常用配搭。

今篇以動詞做重點，整理 `쓰다`、`끼다`、`입다`、`하다`、`신다` 同 `차다`。

## 九個基本配搭

| 物件 | 韓文配搭 | 廣東話意思 |
|---|---|---|
| 🧢 모자 | 모자를 쓰다 | 戴帽 |
| 👓 안경 | 안경을 끼다 | 戴眼鏡 |
| 💍 반지 | 반지를 끼다 | 戴戒指 |
| 👕 옷 | 옷을 입다 | 着衫／着衣服 |
| 👖 바지 | 바지를 입다 | 着褲 |
| 📿 목걸이 | 목걸이를 하다 | 戴頸鏈 |
| 👟 신발 | 신발을 신다 | 着鞋 |
| 🧦 양말 | 양말을 신다 | 着襪 |
| ⌚ 시계 | 시계를 차다 | 戴手錶 |

## 쓰다：戴喺頭或者面

`쓰다` 可以表示將物件戴喺頭上，亦可以用於遮蓋面部嘅物件。

| 名詞 | 配搭 | 廣東話意思 |
|---|---|---|
| 모자 | 모자를 쓰다 | 戴帽 |
| 가발 | 가발을 쓰다 | 戴假髮 |
| 마스크 | 마스크를 쓰다 | 戴口罩 |
| 가면 | 가면을 쓰다 | 戴面具 |

`우산을 쓰다` 亦係常見配搭，意思係「擔遮」。雖然唔屬於穿戴，但可以一齊記住 `쓰다` 呢個用法。

```text
햇빛이 강해서 모자를 썼어요.
因為陽光好猛，所以戴咗帽。
```

## 끼다：套入或者固定喺身上

`끼다` 常用於將物件套入、插入或者固定喺眼、手同手指等位置。

| 名詞 | 配搭 | 廣東話意思 |
|---|---|---|
| 안경 | 안경을 끼다 | 戴眼鏡 |
| 반지 | 반지를 끼다 | 戴戒指 |
| 장갑 | 장갑을 끼다 | 戴手套 |
| 콘택트렌즈 | 콘택트렌즈를 끼다 | 戴隱形眼鏡 |

```text
밖에 나가기 전에 안경을 껴요.
出門之前戴眼鏡。
```

`안경을 끼다` 同 `안경을 쓰다` 都係自然講法。記筆記時可以先跟今篇用 `끼다`，但見到 `쓰다` 唔代表用錯。

## 입다：衣物着喺身體

`입다` 主要用於着喺身體或者腿部嘅衣物。

| 名詞 | 配搭 | 廣東話意思 |
|---|---|---|
| 옷 | 옷을 입다 | 着衫／着衣服 |
| 바지 | 바지를 입다 | 着褲 |
| 셔츠 | 셔츠를 입다 | 着恤衫 |
| 치마 | 치마를 입다 | 着裙 |
| 코트 | 코트를 입다 | 着大褸 |

```text
오늘은 셔츠하고 바지를 입었어요.
今日着咗恤衫同褲。
```

## 하다：佩戴飾物

`하다` 本身用途好多，講穿戴時可以同部分飾物配搭。

| 名詞 | 配搭 | 廣東話意思 |
|---|---|---|
| 목걸이 | 목걸이를 하다 | 戴頸鏈 |
| 귀걸이 | 귀걸이를 하다 | 戴耳環 |
| 액세서리 | 액세서리를 하다 | 戴飾物 |

```text
오늘은 목걸이를 했어요.
今日戴咗頸鏈。
```

## 신다：鞋襪着喺腳

`신다` 用於將鞋、襪等物件着喺腳上。

| 名詞 | 配搭 | 廣東話意思 |
|---|---|---|
| 신발 | 신발을 신다 | 着鞋 |
| 양말 | 양말을 신다 | 着襪 |
| 운동화 | 운동화를 신다 | 着波鞋 |
| 구두 | 구두를 신다 | 着皮鞋 |
| 부츠 | 부츠를 신다 | 着靴 |

```text
양말을 신고 신발을 신어요.
着襪，再着鞋。
```

鞋同襪要用 `신다`，唔用 `입다`。所以係 `양말을 신다`，唔係 `양말을 입다`。

## 차다：扣喺手腕等位置

講穿戴時，`차다` 常用於扣住或者圍住手腕嘅物件。

| 名詞 | 配搭 | 廣東話意思 |
|---|---|---|
| 시계 | 시계를 차다 | 戴手錶 |
| 팔찌 | 팔찌를 차다 | 戴手鏈 |

```text
외출하기 전에 시계를 차요.
出門之前戴手錶。
```

## 總結

可以先按物件戴喺邊個位置去記：

| 位置或者物件 | 動詞 | 代表配搭 |
|---|---|---|
| 頭、面 | 쓰다 | 모자를 쓰다 |
| 眼、手、手指 | 끼다 | 안경을 끼다、반지를 끼다 |
| 身體、腿部衣物 | 입다 | 옷을 입다、바지를 입다 |
| 部分飾物 | 하다 | 목걸이를 하다 |
| 腳上鞋襪 | 신다 | 신발을 신다、양말을 신다 |
| 手腕上扣住嘅物件 | 차다 | 시계를 차다 |

最重要唔係將所有「穿戴」都翻譯成同一個韓文動詞，而係將「名詞 + 動詞」當成一組配搭去記。
