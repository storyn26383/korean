`-기로 하다` 接喺動詞後面，表示決定或者同人約定做某件事。中文可以理解成「決定……」或者「約定……」。

```text
새 화분은 창가에 놓기로 했어요.
我決定將新花盆放喺窗邊。
```

## 文法接法

將動詞嘅 `-다` 刪走，再接上 `-기로 하다`。無論語幹有冇 받침，接法都一樣。

### 冇 받침

語幹冇 받침 時，直接接 `-기로 하다`。

| 動詞 | 語幹 | 變化 |
|---|---|---|
| 가다 | 가- | 가기로 하다 |

### 有 받침

語幹有 받침 時，一樣直接接 `-기로 하다`。

| 動詞 | 語幹 | 變化 |
|---|---|---|
| 먹다 | 먹- | 먹기로 하다 |
| 놓다 | 놓- | 놓기로 하다 |

如果要表達「決定唔做」，可以喺動詞前面加 `안`，或者用 `-지 않기로 하다`。

```text
안 가기로 했어요.
가지 않기로 했어요.
我決定唔去。
```

## 常見形式

### `-기로 했어요`

表示決定或者約定已經作出，係日常對話最常見嘅形式。

```text
내일 다시 만나기로 했어요.
我哋約好聽日再見。
```

### `-기로 해요`

可以喺對話當下提出建議，同對方定下一個約定。

```text
다음에는 늦지 않기로 해요.
我哋約定下次唔好再遲到。
```

### `-기로 했는데`

先講原本作出嘅決定，再接一個同預期唔同嘅情況。

```text
일찍 자기로 했는데 아직 안 잤어요.
我決定咗早啲瞓，但而家仲未瞓。
```

## 例句

### 1. 表達自己嘅決定

```text
새 화분은 창가에 놓기로 했어요.
我決定將新花盆放喺窗邊。
```

`놓다` 刪走 `-다`，再接上 `-기로 했어요`：

```text
놓다 → 놓기로 했어요
```

### 2. 表達同人作出嘅約定

```text
친구하고 토요일에 같이 공부하기로 했어요.
我同朋友約好星期六一齊溫習。
```

句子有 `친구하고`，所以呢度唔單止係自己嘅決定，亦表示同朋友約定好一齊溫習。

### 3. 表達決定唔做某件事

```text
슬픈 영화를 당분간 보지 않기로 했어요.
我決定暫時唔睇悲傷嘅電影。
```

`보지 않기로 했어요` 表示「決定唔睇」。`슬프다` 喺句中變成 `슬픈`，用嚟形容 `영화`。

### 4. 提出一個約定

```text
우리 앞으로 매일 한국어로 한 문장씩 쓰기로 해요.
不如我哋約定由而家開始，每日用韓文寫一句。
```

`-기로 해요` 可以用嚟向對方提出建議，並一齊定下一個約定。

### 5. 決定同實際情況唔同

```text
오늘 일찍 자기로 했는데 숙제가 아직 안 끝났어요.
我決定咗今晚早啲瞓，但功課仲未做完。
```

`-기로 했는데` 先交代已經作出嘅決定，再講一個令件事未必可以照計劃發生嘅情況。作出決定唔代表最後一定有實行。

## 今日單字

### 놓다

**詞性：** 動詞  
**意思：** 將人或者物件放喺某個位置；放低

常見搭配：

```text
책을 책상 위에 놓다
將書放喺書枱上

가방을 의자에 놓다
將袋放喺櫈上

컵을 내려놓다
放低隻杯
```

`놓다` 仲有其他意思同用法，今篇先集中學「放置」呢個基本意思。

今篇例句：

```text
새 화분은 창가에 놓기로 했어요.
我決定將新花盆放喺窗邊。
```

### 슬프다

**詞性：** 形容詞  
**意思：** 傷心、悲傷、難過

常見搭配：

```text
슬픈 영화
悲傷嘅電影

마음이 슬프다
心裏難過

너무 슬퍼요
好傷心
```

`슬프다` 接 `-어요` 時，會變成 `슬퍼요`；放喺名詞前面形容事物時，就會變成 `슬픈`。

```text
슬프다 → 슬퍼요
슬프다 → 슬픈 영화
```

今篇例句：

```text
슬픈 영화를 당분간 보지 않기로 했어요.
我決定暫時唔睇悲傷嘅電影。
```

喺今篇「決定做某個動作」嘅基本用法入面，`-기로 하다` 接喺動作 `보다`，而唔係直接接喺形容詞 `슬프다`：

```text
슬픈 영화를 보지 않기로 했어요.
決定唔睇悲傷嘅電影。
```

## `-기로 하다` 同 `-(으)려고 하다`

兩個文法都可以講之後要做嘅事，但語氣重點唔同。

### `-(으)려고 하다`：打算、計劃

```text
운동을 하려고 해요.
我打算做運動。
```

重點係有做某件事嘅意圖或者計劃。

### `-기로 하다`：已經決定、約定

```text
매일 운동하기로 했어요.
我決定每日做運動。
```

重點係已經作出決定；如果涉及其他人，亦可以表示大家定好咗一個約定。

## 總結

```text
動詞語幹 + -기로 하다
```

`-기로 하다` 主要用嚟：

1. 表達自己已經作出嘅決定。
2. 表達同其他人定好嘅約定。
3. 用 `-지 않기로 하다` 表達決定唔做某件事。
4. 用 `-기로 해요` 提出建議或者約定。
5. 用 `-기로 했는데` 接住講同原本決定唔同嘅情況。
